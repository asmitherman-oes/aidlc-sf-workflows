# Salesforce Platform Primer (Product Lead Reviewer)

Applies only when the active scope is `salesforce-classic` or the workspace contains `sfdx-project.json`. Otherwise ignore this file.

- Check that requirements name the personas' Salesforce licenses and the record
  access each needs, and that every `SFC-n` constraint is testable.
- Flag stories that assume custom builds for standard features, or that omit
  data volume and integration expectations.
