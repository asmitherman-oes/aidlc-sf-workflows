# Salesforce product review criteria

Apply this methodology when the active scope is `salesforce-sdlc-standard` or
the workspace contains `sfdx-project.json`.

Reject product artifacts that convert a requested Salesforce implementation
into a requirement without evaluating the business outcome. Require evidence
for relevant existing org behavior, affected personas and licenses, security
expectations, bulk and error behavior, reporting, accessibility, integration,
and release acceptance. Flag invented metadata names and assumptions presented
as org facts.
