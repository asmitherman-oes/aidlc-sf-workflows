# Salesforce delivery-planning methodology

Apply this methodology when the active scope is `salesforce-sdlc-standard` or
the workspace contains `sfdx-project.json`.

Plan work around metadata dependencies, package directories, org promotion,
validation windows, required test levels, manual setup, data migration, and
release approvals. Make environment ownership and the exact allowed org aliases
visible. Include business owners, Salesforce administrators, security owners,
integration owners, release managers, and support teams where applicable.
Separate deployable metadata, environment configuration, permission assignment,
data operations, and post-deployment verification into traceable tasks.
